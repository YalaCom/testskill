# FULLSIZE — Arizona RP Family

Сайт-приглашение в семью **FULLSIZE** на Arizona RP.

![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-ff5337?style=flat-square)

## Что сделано

- Большой игровой лендинг с редакционной типографикой, фото, анимациями и responsive-вёрсткой.
- Разделы: о семье, принципы, движ, путь вступления, FAQ.
- Рабочая форма, которая собирает **готовый текст заявки**, показывает превью и копирует его по кнопке.
- Раскрывающийся FAQ, мобильная навигация, прогресс прокрутки, анимация появления секций.
- Доступность: управление с клавиатуры, видимый фокус, описанные поля, поддержка reduced motion.
- Без библиотек, сборщиков и сервера. Достаточно открыть index.html в браузере.
- Design system: [design-system/fullsize/MASTER.md](design-system/fullsize/MASTER.md).

## Опубликовать сайт бесплатно через GitHub Pages

В репозитории уже лежит готовый workflow: [.github/workflows/pages.yml](.github/workflows/pages.yml).

**Один раз включи Pages в GitHub:**

1. Открой репозиторий: https://github.com/YalaCom/testskill
2. Открой **Settings → Pages** (прямой путь: https://github.com/YalaCom/testskill/settings/pages).
3. В **Build and deployment → Source** выбери **GitHub Actions**.
4. Если сайт не опубликован автоматически, открой **Actions → Deploy FullSize site to GitHub Pages → Run workflow** и выбери ветку main.
5. После успешного деплоя в Settings → Pages появится ссылка. Ожидаемый адрес для стандартного имени репозитория — https://yalacom.github.io/testskill/.

Если первый запуск workflow упал с «Get Pages site failed / Not Found» — это нормальная ситуация для нового репозитория, у которого ещё не включён Pages. Достаточно выполнить шаг 3 и повторно запустить workflow.

## Где менять содержимое

- index.html — тексты семьи, разделы, формы, изображения.
- style.css — все цвета, размеры, анимация, адаптивность.
- script.js — меню, прокрутка, FAQ и генерация заявки.
- design-system/fullsize/MASTER.md — принципы UI/UX проекта.

Главный акцент #ff5337. Шрифты Unbounded и Manrope подключаются через Google Fonts. Фото загружаются из Unsplash. Для полностью автономной работы можно позже заменить внешние изображения и шрифты локальными файлами.

## Как работает заявка

Пользователь вводит игровой ник, сервер, уровень, способ связи и необязательный текст о себе. Нажимает «Создать заявку» и получает готовое сообщение для копирования.

**Важно:** сайт не отправляет заявку, не сохраняет данные и не связывается ни с каким сервером. Нужно самостоятельно передать скопированный текст представителю FULLSIZE. Эта реализация не требует выдуманного Discord/Telegram-адреса.

## Дальнейшее развитие

Для настоящего приёма заявок владельцу понадобится предоставить один рабочий канал связи (например, адрес Discord webhook, защищённый серверным посредником, или Telegram-бот с backend), а также подтвердить нужный сервер Arizona RP. **Нельзя класть токены и вебхуки с полномочиями в публичный JavaScript.**

## Юридическое примечание

Неофициальный фан-сайт игровой семьи FULLSIZE, не связанный с администрацией Arizona RP. Фото используются как тематические иллюстрации, а не как скриншоты игры.
